# Adaptador local Chopify\n\nO script `run_chopify.py` chama uma instalação local do Chopify. Configure `CHOPIFY_DIR` com a pasta do clone e `CHOPIFY_PYTHON` com o Python do ambiente virtual do Chopify. Configure `MEDIA_ROOT` e `CLIPS_STORAGE_DIR` para as pastas de entrada e saída.\n\nExemplo:\n\n```bash\nCHOPIFY_DIR=/opt/chopify CHOPIFY_PYTHON=/opt/chopify/.venv/bin/python MEDIA_ROOT=./var/media CLIPS_STORAGE_DIR=./var/clips python apps/clipper/run_chopify.py --source ./var/media/video.mp4 --max-clips 5 --min-score 8\n```\n\nO adaptador processa somente arquivos já importados sob `MEDIA_ROOT`, sem `shell=True`, e retorna JSON. Instalação do motor e execução real ainda pendentes.
